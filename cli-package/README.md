# Bizorvia CLI

The coding agent that runs from your terminal, powered by Bizorvia AI.

## Install

```bash
npm install -g bizorvia
```

## Quick Start

```bash
bizorvia login
bizorvia "create a REST API for a todo app in Node.js"
```

## Commands

| Command | Description |
|---|---|
| `bizorvia login` | Connect your Bizorvia account |
| `bizorvia "prompt"` | Run a coding task |
| `bizorvia fix "error"` | Debug an error message |
| `bizorvia explain <file>` | Explain what a file does |
| `bizorvia refactor <file>` | Refactor for clarity and performance |
| `bizorvia test <file>` | Generate unit tests |
| `bizorvia review` | Review your last git diff |
| `bizorvia credits` | Check remaining AI credits |
| `bizorvia logout` | Sign out |
| `bizorvia --help` | Show help |
